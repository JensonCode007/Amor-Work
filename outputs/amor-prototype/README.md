# Amor prototype

Open `index.html` in a browser, or serve this folder locally:

```powershell
python -m http.server 4173
```

Then visit `http://localhost:4173`.

This is a front-end prototype. The shop bag and contact form intentionally provide prototype feedback only; they are ready to connect to real commerce and enquiry systems in a production build.

The opening brand screen holds for about 4.8 seconds, and navigation between hash routes uses a soft fade/slide transition. The supplied Amor statement reference is represented as a responsive live-text section on the homepage.

The homepage hero is now a custom-gifting bento grid. Hovering “Custom gifting” reveals Wooden Works, Stone Art, Sculpture, Mementos, Gift Rocks, Gift Frames, and Paintings.

Each dropdown item now has its own gallery route and a linked customization brief with material selection, engraving/carving text, and studio reference directions.

The header uses the supplied Amor lockup as a transparent `assets/amor-header-logo.png` so the mark blends into the cream header background.
